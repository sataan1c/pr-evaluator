# Дашборд «Карта вклада»

Интерфейс на чистых HTML, CSS и JS, без библиотек и сборки. Языки: азербайджанский, русский, английский.

## Открыть

Основной способ, из корня проекта (данные берутся из `data/`):

```
python app.py
```

Приложение поднимает дашборд на `http://127.0.0.1:8765`, открывает браузер и на каждое обновление страницы перечитывает файлы с диска. Заметки из поля «Контекст от автора» пишутся в `notes.json`.

Без приложения: двойной клик по `index.html`. Данные тогда берутся из `data.js`; этот файл собирает команда из следующего раздела, в репозитории его нет. Заметки в этом режиме остаются в браузере.

Пока PR не оценены моделью, дашборд показывает экран «оценок пока нет»: сколько PR и авторов выгружено, что известно об откатах и исправлениях, и как получить оценки.

## Подставить свои данные без приложения

Из корня проекта (или из папки, где лежит `prs.json`):

```
python dashboard/make_data.py
```

Скрипт собирает файлы конвейера в `dashboard/data.js`. Второй способ: кнопка «Данные» в правом углу и выбор JSON-файлов; они живут до перезагрузки страницы.

| Файл | Что даёт дашборду | Без него |
| --- | --- | --- |
| `prs.json` | заголовки, авторы, изменения | дашборд пуст |
| `scores.json` | баллы, причины, строки кода | экран «оценок пока нет» |
| `metrics.json` | множители и уровни | видны только медианы баллов |
| `outcomes.json` | пометки «откатили», «чинили» | колонки «Исход» нет |
| `validation.json` | раздел «Проверка метода» | в разделе подсказка, как его получить |
| `run_stats.json` | баллы отдельных прогонов, название модели | прогоны не показаны |
| `author_history.json` | ссылки на GitHub, пояснение уровня | ссылок нет |
| `config/levels.json` | разбор «как получился множитель» по слагаемым | показан только итог |

## Запасной вариант на демо

```
python dashboard/make_data.py --single dashboard.html
```

Получится один файл со встроенными стилями, кодом, переводами и данными. Его можно переслать или открыть на любом ноутбуке.

## Языки

Кнопки AZ, RU, EN в шапке переключают язык сразу, без перезагрузки; выбор запоминается в браузере. При первом открытии берётся язык браузера, а если он не из этих трёх, русский.

Все тексты интерфейса лежат в `i18n.js`: по одному блоку на язык с одинаковыми ключами. Чтобы поправить перевод, достаточно изменить строку в нужном блоке. Тест `tests/test_dashboard.py` проверяет, что ключи и подставляемые значения совпадают во всех трёх языках.

Суть PR и причины баллов пишет модель; дашборд показывает их как есть. Их язык задаёт параметр `--lang` при оценке.

## Путь демо в три клика

1. «Команда»: таблица разработчиков с линейкой множителя.
2. Клик по строке разработчика: множитель и из чего он сложился.
3. Клик по PR: четыре балла, причина каждого и строки кода, отмеченные жёлтым.

Для третьего шага выберите PR с пометкой «Откатили» и высоким баллом риска.

## Что где лежит

- `index.html` — каркас страницы: шапка, окно загрузки данных.
- `styles.css` — весь вид. Цвета и шрифты заданы переменными в начале файла, отдельно для светлой и тёмной темы.
- `app.js` — логика. Экраны: `viewTeam`, `viewDev`, `viewPrs`, `viewPr`, `viewCheck`, `viewWaiting` (оценок пока нет).
- `i18n.js` — тексты на трёх языках.
- `data.js` — данные; создаётся скриптом, руками не правится.
